API Reference
Key classes for developers.
from kernel.umer_kernel import UmerKernel
import asyncio

async def main():
    kernel = UmerKernel(total_memory_bytes=512*1024*1024)
    await kernel.init()
    pid = kernel.spawn_process("my_service", priority=0.8,
                                capabilities=["fs.read","net.send"])
    print(kernel.status())
    await kernel.shutdown()

asyncio.run(main())
FAQ

❓ Is the quantum computing real?

The mathematics is exactly correct, simulated on classical hardware via NumPy. Real QPU hardware integration is planned for the future.

❓ Can I install this on my iPhone?

No. Apple's Secure Enclave makes this physically impossible without jailbreaking, which voids warranty and violates ToS.
