# ── Reproducibility policy (H15) ──────────────────────────────────────────────
# Builds must be reproducible. This file declares BOUNDED ranges (>=MIN,<MAX) so a
# fresh `pip install` can never silently pull a breaking major. For fully
# deterministic, hash-pinned installs, generate a lock and install from it:
#
#     pip install pip-tools
#     pip-compile --generate-hashes --output-file=requirements.lock requirements.txt
#     pip install -r requirements.lock
#
# Notes:
#   * `g4f` was REMOVED — free GPT-4o/Claude via reverse-engineered endpoints is a
#     supply-chain + ToS risk and is UNUSED in the codebase (no import sites). If an
#     online AI provider ever needs it, vendor/isolate it behind
#     ai/umer_ai.OnlineProvider with an AIGovernance.check_consent gate (H18).
#   * The legacy linters black/flake8/pylint were REMOVED. Linting/formatting is
#     enforced via Ruff + Mypy (see pyproject.toml and README "Contributing").
#   * `kivy` was REMOVED — Flutter (Dart) is the canonical UI (H11/H25); the
#     Kivy-based kernel/gui.py is legacy drift and must not gate installs on kivy.
