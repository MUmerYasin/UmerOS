## Session 207 - H219 (quantum/qkd.py toy error reconciliation) 🟡
- **Drift-recon:** premise **TRUE**, line refs stale (`key_reconciliation` was at
  **367-396**, not `:354-383`). It really was **oracle reconciliation** — a per-bit
  loop `if reconciled_alice[i] != reconciled_bob[i]: reconciled_bob[i] = 1 - reconciled_bob[i]`,
  which requires Alice's secret key. Nothing in the repo called it (only the
  `quantum/__init__.py` + `__all__` export lists); no QKD test file existed.
  Nuance: `run()` computes QBER **before** reconciliation, so an eavesdropper was
  still detected there — the row overstated that half — but the exported function
  itself was bogus for any caller.
- **Fix (`quantum/qkd.py`):** replaced it with a real **Cascade** implementation.
  1. `cascade_reconcile(alice, bob, *, block_size=4, passes=4, seed=None)
     -> ReconciliationResult` — each pass splits the key into blocks, exchanges
     **block parities only** (`_xor_block`), and binary-searches any
     parity-mismatched block down to one bit (`_binary_locate_and_flip`,
     comparing sub-block parities only, never Alice's individual bits) which Bob
     flips. After pass 0 the key is randomly permuted so even-error
     (parity-invisible) blocks get re-split; block size doubles per pass; stops
     early when a pass corrects nothing.
  2. `ReconciliationResult` — `alice_key`/`bob_key`/`corrected_bits`/
     `parity_bits_leaked`/`passes_used`/`residual_errors` + `leak_fraction`/
     `is_reconciled`. `residual_errors` documented as a **simulator-only
     diagnostic** (neither party can compute it in a real run).
  3. `key_reconciliation(...)` kept as a thin 2-tuple wrapper for compatibility.
  4. QBER threshold promoted to named `QBER_SECURITY_THRESHOLD = 0.11`, used by
     **both** BB84 and E91 (replacing two duplicated magic numbers) and exported.
  5. Docstring rewritten to explain parity-only reconciliation, disown oracle
     behaviour, and carry the §1 Author/License trailer.
- **Test:** `tests/test_qkd_cascade_h219.py` (20 passed). The decisive case is
  `test_even_errors_are_not_corrected`: two errors inside one block leave the
  block parity unchanged, so residual must stay 2 — an oracle would return 0.
  Also: 5 % QBER converges to 0 residual in 3 passes; Alice's key never
  modified; leak reported; tuple API; length mismatch raises; empty keys;
  AST check that neither function compares both keys per-index.
